🤖 Benchmark & Submit Your Custom Agent or Tool

Anyone can benchmark an open-source library, a private container, or a custom LLM pipeline using the local runner, and submit the results to this leaderboard with automatic verification. 

# 1. Install ai-ready-bench CLI
git clone https://github.com/sun-flat-yamada/ai-ready-bench.git
cd ai-ready-bench && uv pip install -e .

# 2. Run benchmark on your custom converter or agent
aiready run \
  --dataset ./data/benchmark-suite \
  --converter custom \
  --name "MyDocAgent-v2" \
  --custom-cmd "python my_agent.py {input} {output_dir}" \
  --output-json ./reports/my_result.json

# 3. Package and verify submission manifest
aiready submit \
  --result ./reports/my_result.json \
  --agent-name "MyDocAgent" \
  --author "your-github-handle" \
  --version "2.1.0" \
  --description "High-speed multi-modal converter with custom OCR and table parser."

# 4. Push branch & Open a Pull Request!
# GitHub Actions will validate checksums and auto-merge into the leaderboard.
